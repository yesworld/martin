# Мартин — химчистка мебели в Москве

Статический адаптивный сайт химчистки мебели на HTML, CSS и JavaScript.

[Открыть сайт](https://yesworld.github.io/martin/)

## Структура

- `dist/` — файлы сайта: страница, стили, скрипты, изображения и шрифты.
- `source/` — оригиналы изображений. Для сайта используются копии; оригиналы не изменяются.
- `deploy.sh` — публикация на GitHub Pages.

## Локальный просмотр

Откройте `dist/index.html` в браузере. Установка зависимостей и сборка не нужны.

## Публикация на GitHub Pages

Нужны Git, настроенные `user.name` / `user.email` и доступ на запись в `origin`. Запуск из корня проекта:

```sh
sh deploy.sh
```

Скрипт публикует содержимое `dist/` в ветку `gh-pages`, создавая коммит и отправляя его в `origin`. Рабочая ветка не переключается.

При первоначальной настройке в GitHub выберите **Settings → Pages → Deploy from a branch → gh-pages → /(root)**.
