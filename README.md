# CleanChaos — выездная химчистка

Статический многостраничный сайт Мартина для Москвы и Московской области. HTML, CSS и JavaScript; небольшой генератор на Node.js без сторонних зависимостей.

[Открыть сайт](https://yesworld.github.io/martin/)

## Структура

- `site/config.mjs` — бренд, телефон, Авито, подтверждённые мессенджеры и `DISCOUNT_PERCENT`.
- `site/templates.mjs` — общие шапка, футер, блоки и шаблоны страниц.
- `site/data/prices.json` — исходные рублёвые тарифы, правила выезда и минимальных сумм. Справочные позиции не публикуются.
- `site/data/services.json`, `portfolio.json`, `faq.json`, `reviews.json`, `images.json` — контент и размеры изображений.
- Блоки FAQ автоматически формируют разметку Schema.org `FAQPage` из тех же вопросов и ответов, которые видны на конкретной странице, включая расчёт выезда.
- `site/pricing.mjs` — единые расчёты в копейках для генератора и браузера.
- `site/calculator.mjs`, `app.js`, `gallery.js`, `styles.css` — интерактивность и общие стили.
- `scripts/build.mjs` — генерация 20 HTML-страниц, данных калькулятора и SEO-файлов.
- `dist/` — готовый сайт, изображения и шрифты; публикуется на GitHub Pages. HTML, CSS и JS здесь генерируются, править их нужно в `site/`.
- `source/` — оригиналы фотографий и логотипа. Они не изменяются.
- `deploy.sh` — генерация и публикация в ветку `gh-pages` без переключения рабочей ветки.

## Локальный просмотр

Требуется Node.js 20 или новее. Установка npm-пакетов не нужна:

```sh
node scripts/build.mjs
mkdir -p /tmp/cleanchaos-preview
ln -s "$PWD/dist" /tmp/cleanchaos-preview/martin
python3 -m http.server 4173 --directory /tmp/cleanchaos-preview
```

Откройте [локальный сайт](http://localhost:4173/martin/). Символическую ссылку создают один раз. Для калькулятора нужен HTTP-сервер: открытие через `file://` не поддерживает загрузку JSON и модулей.

## Как менять цены и контент

1. Измените `DISCOUNT_PERCENT` в `site/config.mjs`. Начальное значение — `10`, значение `0` возвращает базовые тарифы. Исходные цены в `site/data/prices.json` уже не снижены: не применяйте дисконт вручную.
2. Правила выезда и минимальная сумма находятся в `travel` и `minimum` того же JSON. Минимальная сумма работ едина для всех расстояний; при текущем дисконте это 2 700 ₽. Выезд 60 ₽/км сверх 10 км считается отдельно и не зависит от дисконта.
3. Для неизвестных тарифов сохраняйте `null`. Справочные услуги с `referenceOnly: true` не включаются в сайт и калькулятор.
4. Фотографии и кейсы редактируются в `site/data/portfolio.json`. Добавляйте только подтверждённые сведения. Для нового изображения укажите размеры в `site/data/images.json`; у файлов `work-photo-*.webp` должен быть вариант `-480.webp` шириной 480 px.
5. Отзывы добавляются в `site/data/reviews.json`: `{ "author": "…", "text": "…", "sourceUrl": "https://…", "verified": true }`. Пока массив пуст, блок не публикуется.
6. Запустите `node scripts/build.mjs`, проверьте результат и опубликуйте.

Мессенджеры заполняются в `config.messengers`: `{ name, url, textParameter? }`. URL должен вести к подтверждённому контакту; `textParameter` добавляется только если этот сервис действительно поддерживает подготовленный текст в ссылке. Без него посетитель копирует расчёт самостоятельно. Ни сообщение, ни заявка автоматически не отправляются.

## Публикация на GitHub Pages

Нужны Node.js, Git, настроенные `user.name` / `user.email` и доступ на запись в `origin`:

```sh
sh deploy.sh
```

Скрипт сам генерирует страницы, публикует `dist/` в `gh-pages`, добавляет `.nojekyll` и сохраняет рабочую ветку. Версии CSS, JS и JSON зависят от содержимого исходников. При первоначальной настройке в GitHub выберите **Settings → Pages → Deploy from a branch → gh-pages → /(root)**.

После публикации проверьте главную, калькулятор, страницу услуги и несуществующий адрес. Добавьте sitemap в Google Search Console и Яндекс Вебмастер; в Яндекс Вебмастере проверьте региональность «Москва и Московская область». Подтверждённые внешние карточки организации можно добавить после получения ссылок от владельца.

## Собственный домен

Сейчас адрес по умолчанию — `https://yesworld.github.io/martin/`. Будущий `cleanchaos.ru` не считается зарегистрированным или подключённым.

Когда домен подтверждён и настроен, задайте его полный HTTPS-адрес с завершающим `/` через `SITE_URL` при публикации:

```sh
SITE_URL=https://your-confirmed-domain.ru/ sh deploy.sh
```

Либо измените `siteUrl` в `site/config.mjs`. Генератор автоматически меняет базовый путь, canonical, Open Graph, sitemap, JSON-LD и создаёт `CNAME`. DNS и привязка домена в GitHub Pages настраиваются отдельно. При возврате на `github.io` генератор удаляет `CNAME`.
