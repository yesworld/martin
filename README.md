# Мартин — химчистка мебели в Москве

Статический адаптивный сайт на HTML и CSS. Галереей управляет небольшой скрипт на обычном JavaScript. Фреймворки, сборка и внешние сетевые зависимости не нужны.

## Структура

- `dist/index.html` — страница, контент, метаданные и JSON-LD Schema.org (`LocalBusiness`, `OfferCatalog`, `Service`).
- `dist/styles.css` — оформление и адаптивная вёрстка.
- `dist/gallery.js` — листание галереи стрелками и с клавиатуры, счётчик и синхронизация со свайпом; без библиотек.
- `dist/assets/images/` — сжатые WebP-копии изображений для сайта.
- `dist/assets/fonts/` — локальный вариативный шрифт Manrope: кириллица, латиница и лицензия OFL.
- `source/` — оригиналы пользователя. Не редактировать, не перезаписывать и не сжимать файлы в этой папке. Для сайта брать копии и сохранять результаты в `dist/assets/images/`.
- `output/imagegen/master-cleaning-original.png` — оригинал изображения, созданного встроенным imagegen.
- `output/imagegen/master-cleaning-face-v3.png` — актуальная версия первого экрана с лицом по новому предоставленному портрету; используется на сайте в виде двух сжатых WebP-копий.
- `IMAGEGEN.md` — полный промпт генерации.

## Локальный просмотр

Откройте `dist/index.html` двойным щелчком в любом современном браузере. Это обычная статика: сервер, Python, Node.js и установка зависимостей не нужны.

Для размещения на хостинге достаточно загрузить содержимое `dist/`.

## Публикация на GitHub Pages

Нужны Git, настроенные `user.name` / `user.email` и доступ на запись в `origin`. Запуск из корня проекта:

```sh
sh deploy.sh
```

Скрипт использует обычные команды Git, без Node.js, pnpm и дополнительных пакетов. Во временном репозитории в `/tmp` он заменяет содержимое ветки `gh-pages` файлами из `dist/`, добавляет `.nojekyll`, создаёт коммит и отправляет его на `origin`. История ветки сохраняется, рабочая ветка не переключается. Временная папка удаляется при завершении; если изменений нет, новый коммит не создаётся.

После первого запуска в GitHub откройте **Settings → Pages → Deploy from a branch**, выберите ветку **gh-pages**, папку **/(root)** и нажмите **Save**. Следующие обновления публикуются той же командой.

## Когда появятся контакты

В `dist/index.html` найти комментарий `CONTACTS`. Заменить две отключённые кнопки на ссылки с теми же классами: `tel:+7…` и точный URL Авито. Убрать текст «Контакты скоро появятся» и атрибуты `disabled` / `aria-describedby`. Добавить проверенный номер в поле `telephone` у `LocalBusiness`, а ссылку на профиль — в `sameAs`, если это профиль мастера.

Телефон, адрес, отзывы, цены и сроки высыхания не выдуманы. Сейчас контакты — заглушки по просьбе заказчика. Перед общедоступным запуском указать реальный домен для canonical/og:url и абсолютных идентификаторов Schema.org. Москва указана как зона обслуживания, а не как выдуманный офисный адрес.

Первое изображение — сгенерированная сцена с лицом по предоставленному заказчиком портрету, а не документальная фотография; на странице есть подпись. Исходная версия сцены сохранена отдельно. Крупный план чистки ткани также сгенерирован и подписан. Изображение оборудования взято из предоставленного заказчиком оригинала.

В галерее все 14 настоящих снимков `source/photo_*.jpg`. Для каждого есть сжатая копия `dist/assets/images/work-photo-XX.webp` и атрибут `loading="lazy"`; оригиналы не изменялись. Кадры показываются целиком, без обрезки. Галерея поддерживает свайп, кнопки, клавиши ←/→, Home/End и уменьшение анимации по настройкам устройства. Без JavaScript остаётся обычная горизонтальная прокрутка. Снимок `photo_12_2026-09-19_20-28-13.jpg` использован как референс насадки и ткани для генерации крупного плана.
